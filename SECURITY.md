# Политика безопасности

Проект использует публичные API из браузера и не требует серверных API-ключей для обычной работы.

## Поддерживаемая версия

Поддерживается текущая ветка `main`.

## Как сообщить о проблеме

Если нашли уязвимость, не публикуйте детали в issue. Используйте приватное сообщение владельцу через GitHub-профиль или GitHub Security Advisory, если он доступен для репозитория. Укажите:

- краткое описание проблемы;
- шаги воспроизведения;
- возможное влияние;
- версию или commit, где проблема замечена.

## Что считается чувствительными данными

В репозиторий нельзя добавлять:

- `.env` и локальные конфиги с секретами;
- API-ключи, токены и cookie;
- логи с пользовательскими данными;
- дампы баз данных и локальные backup-файлы.

Если случайно добавили чувствительные данные в commit, не публикуйте его. Сначала удалите секреты, перевыпустите ключи или токены и только потом отправляйте исправленную историю.
