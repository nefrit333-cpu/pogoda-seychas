# Погода сейчас

Одностраничный сайт прогноза погоды на Laravel/PHP. Страница сразу запрашивает геолокацию пользователя, определяет город или поселок и показывает текущую погоду, подробный почасовой прогноз на остаток дня и прогноз на 6 дней.

## Возможности

- Автоматическое определение текущей локации через браузерную геолокацию.
- Определение названия города или поселка через BigDataCloud.
- Прогноз из Open-Meteo без серверных API-ключей.
- Почасовой прогноз текущего дня с учетом часа просмотра.
- Ветер отображается в `м/с`.
- Ночной режим включается с `21:00` до `04:59`; днем показывается солнце, ночью луна.
- Разные визуальные сцены для ясной погоды, облачности, дождя и грозы.
- Живые погодные состояния: солнечное свечение, движение облаков, дождь и вспышки грозы.
- Адаптивный интерфейс для desktop и mobile.
- Статический экспорт для Vercel.

## Технологии

- Laravel 13 / PHP 8.3.
- Open-Meteo Forecast API.
- BigDataCloud reverse geocoding.
- Статический экспорт в `vercel/index.html` для публикации на Vercel.

## Локальный запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Откройте `http://127.0.0.1:8000`.

## Статический экспорт

```bash
php scripts/export-static.php
```

Файл для Vercel будет создан в `vercel/index.html`, а изображения погоды будут скопированы в `vercel/weather-assets/`.

## Проверки

```bash
php -l resources/views/welcome.blade.php
php -l scripts/export-static.php
php scripts/export-static.php
```

Для UI-проверки откройте страницу на desktop и mobile. В браузере нужно разрешить геолокацию, иначе можно ввести город вручную.

## Деплой

Сайт публикуется как статическая версия из папки `vercel/`. Перед деплоем выполните:

```bash
php scripts/export-static.php
```

Актуальная опубликованная версия: https://vercel-nine-wine-49.vercel.app

## Безопасность

Проект не требует серверных секретов для обычной работы. Не коммитьте `.env`, токены, cookie, логи и локальные backup-файлы. Подробности в `SECURITY.md`.
