# Как участвовать

Спасибо за интерес к проекту. Это небольшой Laravel/PHP-сайт с одностраничным интерфейсом погоды и статическим экспортом для Vercel.

## Локальный запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Для статической версии:

```bash
php scripts/export-static.php
```

Результат появится в `vercel/index.html`.

## Перед отправкой изменений

- Не коммитьте `.env`, токены, ключи, локальные логи и временные файлы.
- Проверяйте PHP-шаблон командой `php -l resources/views/welcome.blade.php`.
- После изменений интерфейса обновляйте статический экспорт командой `php scripts/export-static.php`.
- Если меняли интерфейс, проверьте страницу на desktop и mobile.
- Для правок текста держите русский интерфейс коротким и понятным.
- Если меняли погодные состояния, проверьте минимум ясный день, ясную ночь, облачность, обычный дождь и грозу.

## Pull request

В описании pull request укажите:

- что изменилось;
- как это проверить;
- есть ли влияние на геолокацию, Open-Meteo или мобильную верстку.
